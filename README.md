# Tercer semestre — Universidad

Mi repositorio de estudio para este semestre. Acá voy a reunir el material de las materias, los apuntes de clase, las prácticas y los trabajos prácticos (TPs), junto con sus avances y resoluciones.

## Organización actual

El material está dentro de `ML 2/Repo/`, organizado por materia:

```text
ML 2/Repo/
├── ML2/                 # Machine Learning II
│   ├── Clases/          # Material teórico en PDF
│   ├── Notebooks/       # Ejemplos y ejercicios en Jupyter
│   └── ML2.md           # Archivo reservado para apuntes de la materia
└── IngSft/              # Ingeniería de Software
    ├── Clases/          # Presentaciones y material de clase
    ├── Practicas/       # Guías de ejercicios y actividades
    ├── Imagenes/        # Figuras utilizadas en los apuntes
    └── Ing_Soft.md      # Apuntes y explicaciones de las clases
```

En `IngSft/` también están el programa, el cronograma y la consigna del TP.

## Cómo usarlo

- Entrar a la carpeta de la materia y consultar los PDFs de `Clases/`.
- Leer los apuntes `.md` desde GitHub o con la vista previa de Markdown del editor.
- Abrir los archivos `.ipynb` con Jupyter o VS Code para ejecutar y modificar los ejercicios. Las dependencias necesarias dependen de cada notebook.
- Incorporar nuevas clases, apuntes y resoluciones de TPs en la materia correspondiente, guardando los avances con Git.

La estructura irá creciendo a medida que avance la cursada y se sumen materias y entregas.
